# `Untitled™`

A [Vencord](https://vencord.dev) plugin that removes the titlebar, moving the buttons next to search.

Originally made by [Kyuuhachi](https://github.com/Kyuuhachi/VencordPlugins/tree/main/Untitled), updated to additionally move window controls.

![Showcase](images/showcase.png)

</div>

## Compatibility

This plugin works on Windows, Linux, and macOS, with both the official client and Vesktop.
Moving window controls is only supported on Windows and Linux.

## Installation

Follow the [documentation](https://docs.vencord.dev/installing/custom-plugins) to setup Vencord for custom plugins, `git clone` this repository into the `src/userplugins` folder, then rebuild Vencord & restart Discord.
